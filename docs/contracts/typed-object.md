## Typed cell, claim and mark records

The typed profile is selected by admitted wire/object/* declarations in Topos. A cell names its selected form, parameter bytes, topos standing and declared restsOn coordinates. Positive ceilings travel; a witnessed join is local; positive floors travel. Claims carry independently admitted origin evidence. Bound projects the admitted history into Obligations and prints its four states; configuration readings do not compute those encounters.

Each sample is a place with TARGET.bound, native receipts.bound and fixture data whose hashes the lock names. After a clone, run `npx @lapxo/bound@0.1.5 samples/typed`; `samples/artifacts` demonstrates another form through the same path. No sample runner or private key is required. The native vector folds the signed histories for compatible claims, both CONFLICT causes, FORBIDDEN, exact withdrawals and reuse, and refuses floor/local. It compares the CELL lines with the directly constructed Obligations scene.
