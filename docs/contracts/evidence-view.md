# Authenticated evidence view

The declared evidence@8 view projects authenticated delivery history of the place. It preserves signatures and key attribution, including admitted receipts from an attest-class key. Evidence grants neither normative authority nor independent observation origins. Existing Topos authority and coverage remain the admission boundary.

A sample is a place: fold its declared evidence view with the instrument. The native-view vector invokes only Bound: bootstrap with an external host signer, sign and land evidence, inspect help, lines and native receipts, inspect authenticated evidence, and redeliver retained signed bytes. No private key, registry or validation executor is shipped. The vector names its external signer parameters explicitly; absence cannot be replaced by a fabricated signature.

The rejected sample contains an uncovered write and altered signed bytes. Both refuse by name. Withdrawals remove only covered normative lines; authenticated delivery remains inspectable. Aliases of one key grant no independence. Native receipt fixture bytes are retained output from the instrument, not observations written by a test.
